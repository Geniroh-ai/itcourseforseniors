Your Digital Workspace

The desktop, files and folders — your computer is like a very organised office. Let's take a tour.

🟢 Beginner ⏱ 12 minutes 📖 Reading

What You'll Learn

  • What the "desktop" is and how to use it
  • Understanding files and folders — the filing cabinet of your computer
  • How to open, save, and close a file
  • Essential keyboard shortcuts that save time
  • What "windows" are and how to manage them

The Desktop — Your Digital Desk

When your computer starts up and you've logged in, you see the desktop. This is your main workspace — the starting point for everything you do on the computer.

The desktop usually shows a background image (called wallpaper) with some small pictures on it called icons. Each icon represents a program or a file. Double-clicking an icon opens it.

🏢

It Really Is Like a Desk

Imagine the desktop as your physical desk at work. The icons are like folders and tools placed on your desk. You pick them up (click them) to use them. The "taskbar" at the bottom is like a notepad showing what you currently have open.

The Taskbar

At the very bottom of the screen (on Windows) or at the top (on a Mac), there's a bar that shows which programs are currently open. You can click on items in the taskbar to switch between them. Think of it as a quick list of everything on your desk right now.

Files and Folders — The Digital Filing Cabinet

Everything on your computer is a file. A photo is a file. A letter you wrote is a file. A music track is a file. To keep things organised, files are placed into folders (also called "directories").

📁

Just Like Physical Filing

Think of a filing cabinet. Inside are hanging folders (like "Family Photos," "Bank Statements," "Recipes"). Inside each folder are individual documents. Your computer works exactly the same way — folders contain files, and folders can even contain other folders.

Common Types of Files

Files come in different types, often shown as a three-letter code at the end of the file name (called an "extension"):

  • .docx or .doc — a Word document (a letter or document)
  • .pdf — a PDF document, often used for forms and official documents
  • .jpg or .png — a photo or image
  • .mp3 — a music file
  • .mp4 — a video file

You usually don't need to worry about these codes — your computer knows which program to use based on the file type and will open it automatically.

Important Folders You'll Find

  • Documents — where your written files and documents live
  • Pictures — where your photos are stored
  • Downloads — where files you download from the internet land first
  • Desktop — files you save directly to your desktop appear here too

Opening, Saving, and Closing

Opening a File

Navigate to where the file is stored (e.g., your Documents folder), then double-click on the file. Your computer will automatically open it in the right program.

Saving Your Work

This is one of the most important habits to build. Save your work regularly so you don't lose it if the computer unexpectedly restarts. There are two types of saving:

  • Save (Ctrl + S on Windows / Cmd + S on Mac) — saves the file in the same place with the same name. Use this often while working.
  • Save As — saves a copy with a new name or in a new location. Use this to create a backup or a new version.
💡

Save Early and Often

Make it a habit to press Ctrl+S (or Cmd+S on a Mac) every few minutes while you're working on something. Think of it like pressing the shutter on a camera — you're capturing your work at that moment.

Closing a File or Program

Click the X button in the top-right corner of any window (Windows) or the red circle in the top-left (Mac). If you haven't saved your work, the computer will usually ask "Do you want to save?" — always say Yes unless you intentionally want to discard your changes.

Windows — Not Just the Operating System

Every program you open appears in a window — a rectangular area on screen. You can have multiple windows open at once, just like having multiple books open on your desk. You can:

  • Minimise — hides the window (the — button). It's still open but not visible. Click it in the taskbar to bring it back.
  • Maximise — makes the window fill the whole screen (the □ button)
  • Restore — returns the window to a smaller size so you can see other things behind it
  • Close — completely closes the program (the X button)
ℹ️

Minimise ≠ Close

A very common mistake: clicking the – button (minimise) makes the window disappear from view, but the program is still running. The X button actually closes it. If something "disappears," check the taskbar — it's probably just minimised.

The Most Useful Keyboard Shortcuts

Keyboard shortcuts are combinations of keys that perform actions quickly, without needing to go through menus. On Windows, you hold the Ctrl key and press a letter. On Mac, you hold the Cmd (⌘) key instead of Ctrl.

⌨️ Essential Shortcuts (Windows / Mac)

Ctrl S

Save

Saves your current document. Use constantly.

Ctrl Z

Undo

Reverses your last action. Made a mistake? Ctrl+Z fixes it. Can be pressed multiple times.

Ctrl C

Copy

Copies selected text or a file to the clipboard (a temporary holding area).

Ctrl V

Paste

Places whatever you copied into the current location. Copy + Paste = duplicating content.

Ctrl P

Print

Opens the print menu so you can print your current document or page.

🔑

The Magic of Undo (Ctrl+Z)

If you accidentally delete something or make a mistake, immediately press Ctrl+Z. It's like a time machine that reverses your last action. You can press it several times to go further back. This one shortcut removes a huge amount of anxiety from using a computer.

Key Takeaways

  • ✓ The desktop is your starting screen — icons open programs and files
  • ✓ Files are stored in folders, just like a physical filing cabinet
  • ✓ Save your work often using Ctrl+S (Windows) or Cmd+S (Mac)
  • ✓ Ctrl+Z undoes mistakes — use it freely and confidently
  • ✓ Minimising a window hides it but doesn't close it; the X button closes it
